# Ebooks gratuitos — Semana 7

- [Buenas prácticas de testing en JavaScript y Node.js — Yoni Goldberg (en español)](https://github.com/goldbergyoni/javascript-testing-best-practices/blob/master/readme-es.md): lee la **sección 3 (Frontend)**, en especial las prácticas **3.4** (no pausar el test y usar el soporte del framework para lo asíncrono), **3.7** (pocos E2E que abarquen todo el sistema) y **3.8** (reutilizar las credenciales de login para acelerar los E2E).
- [Software Engineering at Google — capítulo 11, "Testing Overview"](https://abseil.io/resources/swe-book/html/ch11.html) (en inglés): por qué los tests inestables destruyen la confianza en una suite, con el caso de estudio "Flaky Tests Are Expensive".
