# Webgrafía — Semana 3

## Testing Library (en inglés)

- [Principios guía](https://testing-library.com/docs/guiding-principles): por qué probar como la persona usuaria
- [React Testing Library: introducción](https://testing-library.com/docs/react-testing-library/intro/)
- [Queries y su prioridad](https://testing-library.com/docs/queries/about/)
- [user-event](https://testing-library.com/docs/user-event/intro)
- [Utilidades asíncronas](https://testing-library.com/docs/dom-testing-library/api-async/): `findBy`, `waitFor`, `waitForElementToBeRemoved`
- [jest-dom](https://github.com/testing-library/jest-dom): lista completa de matchers (funcionan igual con Vitest)
- [Common mistakes with React Testing Library — Kent C. Dodds](https://kentcdodds.com/blog/common-mistakes-with-react-testing-library): los errores más frecuentes y cómo corregirlos. Muy recomendado

## Herramientas

- [Testing Playground](https://testing-playground.com/): pega HTML y te sugiere la mejor query
- [Vitest: mocking](https://vitest.dev/guide/mocking): `vi.fn`, `vi.mock` (lo verás a fondo en la semana 5)
- [React Router](https://reactrouter.com/): documentación oficial, para probar componentes con rutas

## Accesibilidad

- [`<label>` en MDN (en español)](https://developer.mozilla.org/es/docs/Web/HTML/Element/label): cómo asociar etiquetas a campos
- [Roles ARIA en MDN](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Reference/Roles): los roles que usa `getByRole`
