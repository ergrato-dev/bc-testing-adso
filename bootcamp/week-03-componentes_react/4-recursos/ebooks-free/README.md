# Ebooks gratuitos — Semana 3

- [Buenas prácticas de testing en JavaScript y Node.js — Yoni Goldberg (en español)](https://github.com/goldbergyoni/javascript-testing-best-practices/blob/master/readme-es.md): lee la **sección 3 ("Frontend")**. Trata separar la interfaz de la funcionalidad, consultar elementos por atributos que no cambian y esperar eventos asíncronos sin pausas fijas.
- [ARIA Authoring Practices Guide (W3C)](https://www.w3.org/WAI/ARIA/apg/) (en inglés): guía libre con los patrones accesibles de componentes comunes (diálogos, pestañas, menús) y sus roles.
