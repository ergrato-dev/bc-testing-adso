# Semana 3 — Componentes React con React Testing Library

> Semana 3 de 9 (+1 opcional) · Tema común: **Front para todo el grupo** · Piso de cobertura: **40%**

La semana pasada probaste la lógica pura del frontend. Ahora pruebas los **componentes**: lo que la persona usuaria ve en pantalla y lo que pasa cuando escribe, hace clic o espera una respuesta del API. Todos los grupos usan React, así que esta semana toda la ficha trabaja la misma receta.

---

## Objetivos

Al finalizar esta semana serás capaz de:

1. Renderizar un componente en un test y encontrar sus elementos como lo haría una persona.
2. Elegir la query correcta según su prioridad y su variante (`getBy`, `queryBy`, `findBy`).
3. Simular interacciones reales con `user-event`: escribir, hacer clic, enviar formularios.
4. Probar estados de carga, vacío y error, y contenido que aparece de forma asíncrona.
5. Envolver componentes que dependen de rutas o de contexto (React Router, autenticación).
6. Detectar problemas de accesibilidad que también impiden probar un componente.
