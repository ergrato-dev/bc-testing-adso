# Videografía — Semana 11

- [Canal de k6 en YouTube](https://www.youtube.com/@k6io) (en inglés): tutoriales cortos del equipo que mantiene k6. Busca "thresholds" y "stages". Puedes activar los subtítulos automáticos en español.
- [Canal de Grafana en YouTube](https://www.youtube.com/@grafana) (en inglés): los videos recientes de k6 se publican aquí. Busca "k6 load testing".

> 💡 Práctica guiada: corre `carga/estres.js` de la receta y, en otra terminal, mira el uso de CPU del proceso del API (`top` o el Administrador de tareas). ¿En qué escalón llega al 100%? ¿Coincide con el escalón donde el throughput deja de crecer?
