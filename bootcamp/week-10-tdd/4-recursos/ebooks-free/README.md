# Ebooks gratuitos — Semana 10

- [Software Engineering at Google — capítulo 12, "Unit Testing"](https://abseil.io/resources/swe-book/html/ch12.html) (en inglés): cómo escribir tests que prueban comportamiento y no implementación, que es lo que permite refactorizar sin miedo en la tercera fase del ciclo.
- [Buenas prácticas de testing en JavaScript y Node.js — Yoni Goldberg (en español)](https://github.com/goldbergyoni/javascript-testing-best-practices/blob/master/readme-es.md): repasa la **sección 1** (anatomía de un test): nombres, AAA y datos de prueba, que en TDD escribes antes que el código.
